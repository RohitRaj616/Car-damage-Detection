# AI Car Damage Detection System

An AI-powered web application that detects vehicle damage using YOLO object detection and estimates repair costs automatically.

## Features
- User Authentication
- Vehicle Registration
- AI Damage Detection
- Repair Cost Estimation
- Flask Backend
- MySQL Database Integration

## Technologies Used
- Python
- Flask
- YOLOv8
- OpenCV
- MySQL
- HTML/CSS

## Installation

```bash
pip install -r requirements.txt
python app.py
```

## Note
Model weights are not included due to file size.
